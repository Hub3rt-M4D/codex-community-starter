# Plan a task

Read the request, repository instructions, and relevant code and tests. Inspect
existing changes without disturbing them; use Git status and diff if available.
Identify the requested behavior, constraints, and material open questions.

Propose a small plan naming likely files, scope boundaries, and observable
acceptance checks. Include suitable tests and verification with available tools.
Resolve blocking questions and establish agreement before implementation;
existing explicit agreement counts. Do not modify application code.
